## 使用说明
- `T01` 用于承接跨产品、架构、设计、规格的总体交付任务和阶段推进。
- `T02` 用于承接联调、测试、部署、安全和上线验收阶段的总清单。
- `T03` 用于约束多 agent 并行执行时的边界、回写顺序和维护权限。
- `T04` 至 `T10` 是一线执行和日常维护的主任务文档，agent 应优先认领其中单一文档执行。
- 总览类文档只做汇总，执行细节不要回写到 `T01/T02`。
- 新增任务类文档时，请继续使用 `T` 前缀编号，并同步更新本索引。

## 派单规则
- 派单时必须指定单一任务文档，例如 `T05` 或 `T08`，不要一次认领多个主责任务。
- 派单时必须同步填写对应文档中的“当前执行 owner”和“交接记录”。
- 执行前先确认“预计输入”已满足；若未满足，先更新“外部依赖登记表”。
- 执行完成后先更新子任务状态和 Done Criteria，再回写 `T01/T02/T00`。

3. 然后按并行能力拆分执行：
