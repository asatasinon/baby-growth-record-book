## 派单规则
- 每个执行任务文档有且只有一个 `执行 owner`。
- 执行 owner 是唯一有权修改对应任务文档的角色。
- 跨任务阻塞须记录在 `外部依赖登记表` 中，不得直接修改其他任务文档。
- 执行状态变更须同步更新本 T00 总看板视图。
- 任何排期或 owner 变更须在对应执行文档的 `变更记录` 中追加一行。
