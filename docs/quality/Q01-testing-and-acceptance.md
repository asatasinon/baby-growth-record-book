## 测试分层
- 单元测试：聚合逻辑、规则判定、数据校验、AI 上下文构造。
- 集成测试：登录、事件写入、汇总重算、趋势查询、导出任务流转。
- 接口契约测试：OpenAPI 请求响应和错误码。
- 端到端测试：小程序关键路径和后台关键管理路径。

## 关键测试场景
1. 同一天多次喂养和排泄记录后，日报汇总正确。
2. 编辑凌晨记录的时间后，旧日期和新日期的汇总都正确更新。
3. 删除体重记录后，体重趋势图自动修正。
4. 多家庭并行使用时，数据不串家庭。
5. 同一家庭不同角色的可见和可写权限正确。
6. AI 在有数据时给出带时间窗口的回答，在无数据时返回数据不足提示。
7. 导出任务失败后可重试，成功后可下载。
8. 疫苗和用药提醒在规则命中时生成提醒事件。
9. 毫秒时间戳在 API、数据库、前端展示间往返一致，跨时区无日期偏移。
10. bigint 主键在高并发写入下保持唯一且不出现类型截断。
11. API 返回的 ID 为字符串，后端可正确将字符串 ID 转为 `bigint` 查询且无精度丢失。

## ID 与时间戳回归清单（可执行）

| 用例编号 | 测试输入 | 期望结果 | 覆盖层 |
| --- | --- | --- | --- |
| ID-REGEX-01 | `family_id=abc` | 返回 `INVALID_ARGUMENT`，`data.field=family_id` | 接口测试 |
| ID-REGEX-02 | `family_id=00123` | 请求可通过校验并正确命中 `bigint(123)` | 集成测试 |
| ID-CONVERT-01 | 响应体中的 `id` 字段 | 始终是字符串，不出现数值类型 | 契约测试 |
| ID-CONVERT-02 | 超大 ID 字符串（接近 `bigint` 上界） | 可正确解析；越界时报 `INVALID_ARGUMENT` | 单元+接口 |
| TIME-BOUNDARY-01 | 23:59:59.999 与次日 00:00:00.000 的事件 | 日汇总按预期落到正确日期桶 | 集成测试 |
| TIME-BOUNDARY-02 | `Asia/Shanghai` 与 UTC 跨日场景 | 前端展示日期正确，无偏移一天问题 | 端到端 |
| TIME-BOUNDARY-03 | `window_start/window_end` 边界值 | AI 时间窗与查询区间一致 | 接口+集成 |

## 性能基线
- 高频写接口在正常负载下响应时间满足首版可用要求。
- 日报生成任务延迟控制在分钟级。
- 常见趋势查询在合理时间窗口内稳定返回。

## 上线验收标准
- 小程序可完整支持核心记录、列表、趋势、提醒、AI 和导出。
- 容器化环境可完成安装、启动、重启和恢复。
- 有备份和恢复脚本或操作手册。
- 核心接口和关键路径具备自动化测试基础。
