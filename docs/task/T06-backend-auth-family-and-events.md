## 任务背景
- 登录、家庭、宝宝、统一事件服务是所有业务能力的底座。
- 若底座职责不清，会直接影响 `T05`、`T07`、`T08`、`T10` 的执行。

## 任务范围

### 负责范围
- 微信登录、用户身份绑定、JWT 签发与刷新。
- 家庭创建、成员邀请、角色变更、家庭时区等能力。
- 宝宝档案管理。
- 统一事件的创建、编辑、删除、查询和审计日志。
- 管理后台基础查询接口。

### 不负责范围
- 周期汇总、趋势、提醒和异步任务调度。
- AI 问答、导出、分享令牌。
- 部署、安全配置和备份恢复实施。

## Agent 执行边界

### 允许维护
- 当前文档 `T06`
- 与 auth、family、baby、event、admin 基础接口相关的说明
- 必要时回写 `T10` 中与核心链路相关的缺陷项状态

### 禁止越界
- 不直接修改 `T07` 的汇总和提醒任务拆解。
- 不直接修改 `T08` 的 AI、导出和分享方案。
- 不以临时实现便利替代 `T04` 已冻结的字段语义。

## 预计输入
- `T04` 提供的 API、实体、DDL 冻结结论。
- `D02` 中的注册登录、家庭初始化、统一事件写入流程。
- 微信登录接入信息和测试凭证。
- 来自 `T05`、`T10` 的联调问题和权限验证问题。

## 预计输出
- 登录、家庭、宝宝、事件和后台基础接口能力。
- 统一事件写入与审计基础。
- 供 `T07` 派生任务消费的稳定事件输入。
- 供 `T05` 和 `T10` 联调的核心 API 版本。

## agent 接手说明
1. 接手前确认本任务只覆盖登录、家庭、宝宝、事件和后台基础接口。
2. 接手后立即把“当前状态”改为 `进行中`，并登记正在负责的模块。
3. 所有新增接口、角色校验、审计写入变化都先回写本任务文档。
4. 发现需要改动汇总、提醒、导出或 AI 逻辑时，不越界修改，先登记外部依赖。
5. 交接前必须写清楚已完成模块、未完成模块、关键风险和需下游联调的接口。
